# 02 — MDPs, rewards, policies, and model-based RL

## The Markov property

A state is Markov if the future depends on the history only through the current state and action:

\[p(s_{t+1}\mid s_{0:t},a_{0:t})=p(s_{t+1}\mid s_t,a_t).\]

An **MDP** consists of states `S`, actions `A`, transition probabilities `P(s'|s,a)`, reward function `R(s,a,s')` (or an equivalent convention), discount `γ`, and usually initial-state distribution `ρ₀`. In a partially observed setting, raw observations generally fail the Markov property.

An **episode** is one interaction run. A **trajectory** `τ=(s₀,a₀,r₁,s₁,...,s_T)`. A policy is `π(a|s)`; a deterministic policy writes `a=π(s)`.

The discounted return after time `t` is

\[G_t=\sum_{k=0}^{\infty}\gamma^k r_{t+k+1}.\]

Why discount? Often because distant rewards are less certain, to ensure convergence, or to express preference; it is not inherently a physical law. For episodic fixed-horizon tasks, undiscounted returns can also be valid.

## Value functions from first principles

`V^π(s)=E_π[G_t|s_t=s]` measures how good a state is under policy π. `Q^π(s,a)` is the expected return when we take `a` first and follow π afterward. The Bellman expectation identity is a one-step recursion:

\[V^\pi(s)=\sum_a\pi(a\mid s)\sum_{s'}P(s'\mid s,a)\left[R(s,a,s')+\gamma V^\pi(s')\right].\]

Read it aloud: value now = immediate expected reward + discounted expected future value. It works because the state is Markov. The optimality version chooses actions with maximum expected value.

### Tiny example

From state A, `left` gains 2 now and terminates; `right` gains 0 now, leads surely to B, then B gives 5 and terminates. With `γ=0.9`, `Q(A,left)=2`, `Q(A,right)=0+0.9*5=4.5`, so right wins despite zero immediate reward.

## Where a world model enters

**Model-free** RL can learn policy/value directly from transitions without explicitly predicting next state. **Model-based** RL learns or is given transition/reward models and uses them for synthetic trajectories, planning, or value improvement. Not all models are neural and not all model-based agents perform search at deployment.

Two alternative control paths:

```text
model-free:  data -> learn value or policy -> act
model-based: data -> learn transitions/reward -> imagine -> search or train actor -> act
```

A model can improve data efficiency (fewer real interactions) but introduce **model bias**. A planner tends to find and exploit any optimistic error in the learned model, so lower prediction error does not always imply better decisions.

## Exploration and distribution shift

Your model only sees transitions generated by its data collection policy. If training always turns left, predictions for unseen sharp-right turns are extrapolation, not knowledge. Policy updates change visitation patterns, creating a feedback loop: the new policy visits states where the old model is least reliable.
