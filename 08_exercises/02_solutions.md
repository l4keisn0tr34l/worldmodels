## Derivation answers

**D1.** Predicted `A=.7*.9+.3*.4=.75`, `B=.25`. With observation y unnormalized `(.75*.2,.25*.8)=(.15,.20)`, posterior `(3/7,4/7)≈(.4286,.5714)`. No observation: remain `(.75,.25)`.

**D2.** `G_t=r_(t+1)+γ G_(t+1)`; condition on next state/action and apply Markov property, then expectation over π and P yields the Bellman equation in `02_mdp_rl.md`.

**D3.** Jensen gives `ELBO=E_q log p(x,z)−E_q log q(z|x)`. Bayes gives `log p(x)=ELBO+KL(q(z|x)||p(z|x))`. Nonnegative KL means lower bound. `q` equals true posterior when gap 0; prior equals posterior only when x gives no information about z under model (or degenerate cases).

**D4.** `E[(Y−ŷ)²]=.5(−2−ŷ)²+.5(2−ŷ)²=4+ŷ²`; best ŷ=0, error=4. But 0 is not a possible outcome; distribution with mass at ±2 preserves multimodality and can be judged by proper probabilistic scoring rules.

**D5.** `e_H≤ε∑_{j=0}^{H−1}L^j`. If `L≠1`, `ε(L^H−1)/(L−1)`; if `L=1`, `εH`. Region validity, bounded one-step error, and stable local Lipschitz constants may fail badly under policy-induced OOD states.

**D6.** Best returns: 4 at a=.2 and 3 at a=.7. Mean `(.2+.7)/2=.45`; population std `.25`, sample std `sqrt(.125)≈.3536`. Code may fit population or sample estimator; define it. No action gradients are used.

**D7.** One-step `2+.9*3=4.7`. Two-step `2+.9*4+.9²*5=9.65`. λ=.5 gives `7.175`. If terminal after first reward, continuation=0, so later rewards and bootstrap are excluded; return 2.

**D8.** Constant vectors: zero variance, so variance penalty prevents collapse. `[1,1],[2,2],[3,3]` has nonzero feature spread but perfectly correlated coordinates; covariance penalty discourages duplicated dimensions.

**D9.** No deterministic predictor can identify which surface from indistinguishable observation histories. A posterior over surfaces and predictive mixture over braking outcomes is sensible; gather tactile/friction evidence or choose a safer action conditioned on risk.

**D10.** Split by whole trajectories (and possibly environment/host/time, depending on deployment). Random near-duplicate windows leak autocorrelation. One-step error conditions on real state; open-loop uses own predictions; true causal intervention comparison requires action variation or controlled experiment. Without such data, counterfactual validity is unidentifiable from purely observational matching.
